# enveda-arch: High-Performance Continuous MS/MS Neural Architecture

A domain-adapted, mathematically grounded neural architecture for small molecule identification from high-resolution tandem mass spectrometry (MS/MS) spectra in the **Enveda CASMI 2026** competition.

---

## 1. Mathematical Principles & Theoretical Formulation

Unlike generic NLP/audio models (Transformers, Mamba) that treat mass spectra as sequences of discrete tokens, **enveda-arch** models MS/MS spectra as **continuous 1D point clouds**:

$$S = \{(m_i, I_i)\}_{i=1}^P \subset \mathbb{R}_{>0} \times [0, 1]$$

accompanied by the dual **Neutral Loss Point Cloud**:

$$L = \{(\Delta m_i, I_i)\}_{i=1}^P, \quad \Delta m_i = M_{\text{prec}} - m_i$$

### Core Mathematical Components:
1. **Continuous-Filter Convolution (`cfconv`)** (inspired by SchNet, *arXiv:1706.08566*):
   Operates directly on continuous sub-ppm coordinate differences $\Delta m_{ij} = m_i - m_j$ without discretization:
   $$\mathbf{x}_i^{(l+1)} = \sum_{j=1}^P \mathbf{x}_j^{(l)} \odot W(\Delta m_{ij})$$
   where $W(\Delta m)$ is dynamically generated by a continuous Radial Basis / Fourier filter network.
2. **Log-Spaced Random Fourier Features** (*arXiv:1605.02536*):
   Encodes continuous coordinates across scales from $10^{-3}\text{ Da}$ (sub-ppm mass accuracy) to $10^{3}\text{ Da}$ (macro mass offsets).
3. **Collision Energy Conditioning via FiLM**:
   Multi-energy fragmentation dynamics ($E \in \{20, 40, 60\}\text{ eV}$) are conditioned via Feature-wise Linear Modulation:
   $$\tilde{\mathbf{x}} = \gamma(E) \odot \mathbf{x} + \beta(E)$$
4. **Asymmetric Loss (ASL)** (*arXiv:2009.14119*):
   Tackles the 98% class imbalance in high-dimensional molecular fingerprints (Morgan / ECFP4):
   $$L = -y (1-p)^{\gamma_+} \log(p) - (1-y) (p_m)^{\gamma_-} \log(1 - p_m), \quad p_m = \max(p - m, 0)$$
   Hard-thresholds easy negative samples when $p < m$, focusing 100% of gradient updates on informative structural fragments.
5. **Fused Triton Kernel**:
   Custom GPU kernel in Triton for continuous coordinate pairwise RBF distance computation and feature aggregation, executing in register memory.
